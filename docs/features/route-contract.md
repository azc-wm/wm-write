# Route contract

Astro remains the router: the files under `src/pages/` define what is actually rendered. This document records the starter's owned routes and reserved namespaces; it does not register routes or generate pages.

## Starter-owned system routes

| Route | Status |
| --- | --- |
| `/` | Home page |
| `/blog` | Writing archive |
| `/blog/*` | Article pages from the blog collection |
| `/rss.xml` | Generated RSS feed |
| `/robots.txt` | Generated crawl policy |
| `/sitemap-*` | Sitemap resources generated by Astro's sitemap integration (currently `sitemap-index.xml` and `sitemap-0.xml`) |

## Reserved page routes

| Route | Status |
| --- | --- |
| `/about` | Reserved page namespace; the starter currently ships this page |
| `/cv` | Reserved for an optional user page; not currently implemented |
| `/projects` | Reserved for future first-class project support; not implemented |
| `/projects/*` | Reserved project namespace; not implemented |

Reservation communicates that these paths belong to the starter's page concepts. It does not mean a page exists: `/cv` and `/projects` currently return the normal not-found response unless a site author adds a page. `/blog/*`, generated feed/robots/sitemap resources, and `/about` are already implemented.

## Navigation relationship

Primary navigation lives in `src/site.config.ts` as explicit `{ label, href, shortcut }` entries and renders in the header. The configured `href` is the path; there is no second route-to-path mapping. External links remain explicit `href` values in `site.links`; they render in the footer on the copyright row, with copyright left and links right.

Keyboard code remains route-name agnostic: it finds the rendered navigation link carrying the configured shortcut and activates it. Adding or changing a link or shortcut does not add route semantics to the keyboard controller.

## Adding a custom page

There is no generic authored-page collection, dynamic page discovery, or route plugin. Add a page directly using Astro, for example `src/pages/uses.astro`. Avoid the owned and reserved paths above. `/projects` is only reserved; this slice does not add project content, an archive, or detail routes.

There is intentionally no route registry, second router, or scan of arbitrary Astro files for collisions. Astro's filesystem routing remains authoritative; this document communicates the reserved namespaces. Keep the navigation `href` values aligned with the existing Astro pages when changing the starter.
