# Changelog

## 0.1.0 — 2026-10-07

- First release of wm-write, an opinionated, keyboard-friendly static Astro starter for technical and personal writing.
- Includes Markdown and MDX article bundles, light and dark themes, keyboard navigation, SEO metadata, RSS, sitemap generation, and Cloudflare Workers static deployment configuration.
